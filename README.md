# AI Crew

Research and blueprints for a small, supervised AI agent crew: one lead that does most of the work, a small-task worker, a senior advisor used sparingly and an independent reviewer from another vendor, with checks, CI and the owner as the judges.

## Layout

| Folder | Holds |
| --- | --- |
| [`resources/`](resources/) | Input material: findings, notes and summaries from earlier sessions and outside sources |
| [`blueprints/`](blueprints/) | Starting structures under development, such as the starter crew repo |
| [`outputs/`](outputs/) | Finished deliverables: reports and knowledge articles |
| [`recommendations/`](recommendations/) | Proposed decisions for the owner: what to adopt, where and when |
| [`docs/`](docs/) | Project brief, numbered decisions, rejected ideas |
| [`BOARD.md`](BOARD.md), [`JOURNAL.md`](JOURNAL.md) | Task board with the owner's queue; dated log of what happened |
| [`AGENTS.md`](AGENTS.md), [`CLAUDE.md`](CLAUDE.md) | Rules for all AI agents; Claude crew setup |
