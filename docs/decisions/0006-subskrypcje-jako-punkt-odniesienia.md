# 0006: Claude Pro i ChatGPT Plus bez płatnego API jako punkt odniesienia

- **Data:** 2026-11-11
- **Status:** przyjęta
- **Podstawa:** Owner 11.11.2026: najniższe płatne plany, „zapisz jako punkt odniesienia, nie jako stałą”; bez dodatkowych kosztów na API; Opus często trafiał w limit, Sonnet przy małej liczbie zapytań nie, Haiku dobrze radził sobie z prostymi zadaniami

## Decyzja

Koncepcja załogi i blueprinty są projektowane pod Claude Pro i ChatGPT Plus, bez płatnego API. Na co dzień pracują Sonnet i Haiku, Opus tylko punktowo. Największe modele nie są modelami codziennymi.

## Powód

To są realne warunki Ownera. Rozwiązanie, które wymaga wyższego planu albo API, nie byłoby używane.

## Kiedy wrócić

Przy zmianie planu, zmianie limitów albo nowej generacji modeli. Wtedy trzeba powtórzyć ocenę z raportu (rozdział 10).
