# Project ideas

Preliminary analyses of ideas for new projects, kept here until a repository exists for them. Written at the owner's request.

- One file per idea: `short-name.md`. A long text for the owner to analyse may be in Polish.
- `sources/` holds the input material as received. Never edit it.
- An analysis states what is confirmed and what is not, and ends with questions for the owner and the first tasks.
- When the owner starts a repository for an idea, the analysis is the input for that repository's `docs/brief.md`, and the status below changes to `repository: <name>`.
- No personal data and no confidential material here: no client documents, no manuscripts under review, no recordings.
