# Project ideas

Preliminary analyses of ideas for new projects, kept here until a repository exists for them. Written at the owner's request.

## Layout

- **One folder per idea**, named in English kebab-case (`short-name/`).
- In each folder, `README.md` is the crew's main analysis. GitHub shows it when the folder is opened.
- The owner may add any other files to the folder: notes, reports, drafts, images. The crew lists them in the table of files at the end of `README.md` at its next update, and never edits or deletes them.
- Shared material for several ideas stays in `sources/`. Never edit files in `sources/`.
- Cross-project analyses (not tied to one idea) stay at this level as single files.

## Rules

- An analysis states what is confirmed and what is not, and ends with questions for the owner and the first tasks. A long text for the owner may be in Polish; tasks are in English.
- When a repository is started for an idea, the folder's `README.md` is the input for that repository's `docs/brief.md`, and the status below changes to `repository: <name>`.
- No personal data and no confidential material here: no client documents, no manuscripts under review, no recordings.
